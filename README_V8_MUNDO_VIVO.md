# El Creador V8 — Mundo Vivo

Cambios principales:

- Mundo NPC dinámico: todos los creadores avanzan cada trimestre.
- Los creadores pueden crecer, perder seguidores, hacerse virales, conseguir sponsors y sufrir polémicas/funas.
- Se generan nuevos creadores ficticios cada año para mantener viva la categoría Revelación.
- Los NPC también pueden colaborar entre ellos.
- Las colaboraciones del jugador aparecen como invitaciones automáticas; ya no es necesario proponerlas manualmente.
- Las invitaciones tienen escala según seguidores, nicho, fama, crecimiento y networking.
- Streamer Revelación queda restringido al año de debut.
- Streamer del Año pondera fuertemente la escala del creador para evitar que un canal de pocos miles de seguidores termine automáticamente entre los cinco mejores.
- Conversión de vistas a suscriptores revisada para que los canales grandes tengan cifras grandes pero realistas y los canales pequeños no queden congelados.
- Un trimestre sigue teniendo 30–150 videos propios del jugador, con un único video destacado elegido manualmente.
- Las métricas anuales usan los datos del año actual y no contaminan los Awards con estadísticas de temporadas anteriores.
- Sponsors siguen apareciendo automáticamente y Nike/Adidas tienen requisitos altos.
- Se mantiene el flujo: video → Pasan Cosas → decisiones → colaboración/sponsor si corresponde → cierre → T2 → resumen anual.
- Se mantienen 2 trimestres por año.

## Validación

Todos los archivos JavaScript del proyecto fueron comprobados con `node --check`.
