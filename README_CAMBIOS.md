# El Creador — build actualizado

Cambios principales:
- 2 trimestres = 1 año.
- El jugador elige 1 video destacado por trimestre.
- Después de elegirlo, el propio canal publica entre 30 y 150 videos en ese trimestre.
- El volumen de videos cuenta para sus estadísticas, vistas, ingresos y crecimiento.
- Las vistas ahora escalan con los suscriptores: un canal grande puede tener decenas/cientos de miles de vistas por video sin hacer crecer un canal chico de golpe.
- Los sponsors aparecen automáticamente después de los resultados; no hace falta "generarlos" desde el botón.
- Umbrales de sponsors escalonados: marcas grandes no aparecen a los 100k.
- Eventos con decisiones aparecen de forma aleatoria después de algunos trimestres.
- Resumen anual antes de los Awards.
- Coscu Army Awards muestra claramente si ganaste o perdiste.
- Botón para borrar la carrera y empezar de cero desde el dashboard.
- Se agregó favicon inline para evitar el 404 de favicon.
- Se corrigió el guardado del resultado del trimestre.
- Se corrigió el envío de atributos del video destacado.
- Se agregaron animaciones y estados visuales al dashboard/resultados.

IMPORTANTE:
Al reemplazar los archivos en GitHub Pages, borrá la partida vieja desde el botón "BORRAR CARRERA" o desde DevTools > Application > Local Storage si querés probar desde cero.
